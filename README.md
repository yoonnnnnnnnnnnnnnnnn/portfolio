# 전하윤 포트폴리오 웹사이트

시안(`웹포트폴리오.fig`)을 그대로 옮긴 반응형 포트폴리오 사이트입니다.
HTML · CSS · 자바스크립트만 사용했고, 라이브러리나 설치 과정이 없습니다.

---

## 1. 사이트 열기

`site/index.html` 을 더블클릭하면 바로 열립니다.

폰트가 깨져 보이면 아래 명령으로 로컬 서버를 켜고 `http://localhost:8000` 으로 접속하세요.
(내 컴퓨터 안에서만 도는 서버라 외부에 공개되지 않습니다. 끄려면 터미널에서 `Ctrl + C`)

```bash
cd "/Users/jeonhayoon/Desktop/클로드/웹포트폴리오/site" && python3 -m http.server 8000
```

## 2. 유튜브 / 인스타 링크 넣기 — 가장 쉬운 방법

### ① 편집 모드 켜기

브라우저 주소창의 주소 **맨 뒤에 `#edit` 을 붙이고** 엔터를 누릅니다.

```
http://localhost:8000/#edit
```

화면 아래에 검은 막대가 뜨고, 빈 카드마다 점선과 **＋ 링크 넣기** 표시가 생깁니다.

### ② 카드 눌러서 링크 붙여넣기

빈 카드를 누르면 입력창이 열립니다.

| 칸 | 설명 |
|---|---|
| **링크** | 유튜브나 인스타그램 주소를 그대로 붙여넣기 (필수) |
| 제목 | 카드 아래에 보일 제목 (선택) |
| 태그 | 쉼표로 구분해서 입력 → `#태그` 로 표시됨 (선택) |
| 날짜 | 예) 2024.07.07 (선택) |
| 썸네일 | 이미지 파일 경로 (선택) |

**유튜브는 주소만 넣으면 썸네일이 자동으로 붙습니다.**
인스타그램은 썸네일을 자동으로 가져올 수 없어서, 이미지를 직접 넣고 싶으면
사진 파일을 `assets/img/` 폴더에 넣고 썸네일 칸에 `assets/img/파일이름.jpg` 라고 적으면 됩니다.

이미 채운 카드를 다시 누르면 수정하거나 **비우기** 로 되돌릴 수 있습니다.

### ③ 영구 저장하기

편집한 내용은 일단 이 브라우저에만 저장됩니다.
파일에 영구히 남기려면 아래 막대에서

- **[data.js 내려받기]** 를 누르고 → 내려받은 `data.js` 파일을
  `site/assets/js/data.js` 위치에 **덮어쓰기**

하면 끝입니다. (다른 컴퓨터에서 열어도, 나중에 인터넷에 올려도 그대로 보입니다.)

`[코드 복사]` 를 눌러 코드를 클립보드에 담은 뒤 `data.js` 를 열어 전체를 갈아끼워도 됩니다.
`[초기화]` 는 지금까지 넣은 링크를 지우고 `data.js` 내용으로 되돌립니다.
`[끄기]` 를 누르면 편집 모드가 꺼집니다.

## 3. 파일을 직접 고치고 싶다면

`assets/js/data.js` 파일 하나만 고치면 됩니다.

```js
{ url: "https://www.youtube.com/watch?v=xxxxxxxxxxx",
  title: "영상 제목",
  tags: ["부동산", "부산고급빌라"],
  date: "2024.07.07",
  thumb: "" }
```

- `url` 을 `""` 로 두면 시안처럼 **빈 카드**로 보입니다.
- 카드를 더 늘리려면 `{ ... }` 한 덩어리를 복사해서 아래에 붙여넣으세요.
- 채널 이름 · 소개글 · 구독자 수 같은 텍스트도 이 파일에서 바꿀 수 있습니다.

---

## 4. 카드를 누르면

- **유튜브** → 사이트 안에서 팝업으로 바로 재생
- **유튜브 쇼츠 / 인스타 릴스** → 세로 팝업으로 재생
- 팝업은 `ESC`, 바깥 클릭, X 버튼으로 닫힙니다.
- 인스타그램은 비공개 계정이거나 삭제된 게시물이면 재생되지 않습니다.
  이럴 땐 팝업 아래의 "인스타그램에서 보기" 를 누르면 원본으로 이동합니다.

## 5. 폴더 구조

```
site/
├─ index.html                 페이지 본문·텍스트
├─ README.md                  이 문서
└─ assets/
   ├─ css/style.css           디자인 (색상·간격·반응형)
   ├─ js/data.js              ★ 링크를 채우는 파일
   ├─ js/main.js              카드 그리기 · 재생 팝업 · 캐러셀
   ├─ js/edit.js              편집 모드
   ├─ fonts/                  민산스, 더페이스샵 잉크립퀴드, ylee MHIM (웹용으로 변환)
   └─ img/                    편지·프로필·스킬 아이콘 이미지
```
